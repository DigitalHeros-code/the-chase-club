# The Chase Club — Delhi's Running & Fitness Crew

> "We chase pace, not perfection."

The Chase Club is a running and fitness crew based in Delhi for people who show up at dawn, run weekly sessions, and race together.

## Features
- **Modern Responsive Design**: Editorial-style typography and dark/paper aesthetic.
- **Weekly Events & Meetups**: Lodhi Loop, Track Tuesdays, Season Openers, Recovery runs.
- **Fast & Lightweight**: Pure HTML and CSS with zero external JS dependencies.
- **Vercel Ready**: Pre-configured for immediate deployment on Vercel.

## Project Structure
```text
├── assets/
│   └── chase-club-logo.jpg   # Brand logo and mark
├── .gitignore
├── index.html                # Main landing page
├── README.md
└── vercel.json               # Vercel configuration
```

## Running Locally
Simply open `index.html` in any modern web browser or serve with any static HTTP server.

## Deploying to Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML).
3. Click **Deploy**.
